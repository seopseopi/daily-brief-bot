# 배너 제작 기록

[`morning-brief-cover.svg`](morning-brief-cover.svg)는 이 저장소를 위해 만든 코드 기반 벡터 일러스트입니다. 크림색 바탕, 짙은 청록색 글씨, 일출색 포인트로 아침의 차분한 분위기를 표현했습니다. 외부 사진·폰트 파일·개인 일정은 포함하지 않습니다.

- 크기: **1280 × 480**, SVG 원본
- 소재: 떠오르는 해, 달력, 체크리스트
- 이미지의 `07:30`: 목표 예약 시각을 나타내는 장식이며 정시 도착을 보장하는 값이 아닙니다.
- 성격: 브랜드 일러스트. 실제 Discord 화면 또는 실제 수집 결과가 아닙니다.

사용자의 다른 저장소인 [집장부](https://github.com/seopseopi/Jipjangbu), [XRD Studio](https://github.com/seopseopi/XRD_Studio), [C++ 팀 프로젝트](https://github.com/seopseopi/C-_2026_teamProject)의 중앙 정렬 커버·배지·한국어 기능 설명·실행 안내 흐름을 이어갑니다. 배너 색과 소재는 아침 브리핑의 용도에 맞춰 별도로 구성했습니다.
