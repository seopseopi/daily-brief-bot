# 데이터 소스와 표시 원칙

[처음으로](../README.md) · [설정 안내](configuration.md) · [운영·문제 해결](operations.md)

숫자나 게시물이 있다는 이유만으로 최신 데이터로 취급하지 않습니다. 발행시각·거래시각·조회 상태를 함께 표시하고, 원문을 확인할 수 있는 링크를 제공합니다.

| 영역 | 소스 | 표시 원칙 |
| :--- | :--- | :--- |
| 개인 일정 | 비공개 iCal(ICS) · 고정 시간표 | 반복·취소·종일 일정 반영. 정상 0건·미연결·조회 실패 구분 |
| 과제 | Discord 과제 채널 · 수동 목록 | 명시적 명령 우선. 미완료 과제와 연체 상태 유지 |
| 날씨·대기질 | [Open-Meteo](https://open-meteo.com/en/docs) | 모델 예보·대기질 모델. 확정된 관측값으로 표현하지 않음 |
| 뉴스 | 연합뉴스 · 한국경제 RSS | 기본 최근 36시간 중 발행시각 확인된 기사. 원문·매체 리드문 우선 |
| 시장 | 네이버페이 증권 · Yahoo Finance | 실시간·전일 종가·정규장 종가와 거래시각 구분 |
| 학사공지 | 국민대 컴퓨터공학부 · SW중심대학 | 파서가 빈 결과를 반환하면 실패로 표시 |
| 스포츠 | 네이버 스포츠 | 두산 경기·순위, 조회 기준 향후 7일의 다음 경기와 해외축구 |
| 공부 | arXiv | 최근 7일 논문과 초록 기반 설명, 원문 링크 |
| 커뮤니티 | DCInside · Reddit · Hacker News | 기본 최근 24시간, 플랫폼 다양성을 고려. **사실 확인 필요** 명시 |

일부 어댑터는 비공식 또는 문서화되지 않은 공개 엔드포인트를 사용합니다. 공급자 응답·페이지 구조가 바뀌거나 데이터가 오래되면 일부 섹션의 조회가 실패할 수 있습니다. 실패 항목을 현재 값처럼 보이는 대체 데이터로 채우지 않습니다.

## 요약을 읽는 기준

- **핵심 3줄:** 일정·마감·날씨·최신기사 데이터를 규칙으로 선정합니다. LLM이 새로운 사실을 만들어 작성하지 않습니다.
- **날씨:** 일별 강수확률의 최대값과 현재 시각의 예보를 구분합니다. 대기질의 `US AQI`는 미국 지수이며 국내 등급과 같은 척도가 아닙니다.
- **뉴스:** 제목·발행시각·출처를 붙입니다. 피드 URL의 잘못된 `&` 문자는 복구하고, 연합뉴스 분야별 피드가 실패하거나 최신 기사가 없으면 한국경제의 같은 분야 피드를 조회합니다. 대체 출처에도 동일한 최신성 기준을 적용합니다. 관련 보도 링크는 추가로 읽을 자료이며 교차 검증 완료 표시가 아닙니다.
- **시장:** 간밤 흐름과 변동성 지표는 관측값 요약입니다. 매매 신호나 예측으로 다루지 않습니다.
- **커뮤니티:** 사실 보도와 구별되는 반응 신호 또는 정보 링크 후보입니다. 대표성이나 내용의 정확성을 보장하지 않습니다.
- **AI 요약:** 사용할 경우 원문 기반 압축임을 구분합니다. 원문을 확인할 수 있는 링크를 유지합니다.

## 외부 전송과 상태

`ANTHROPIC_API_KEY`를 설정하면 자연어 과제 메시지, 논문 초록, 선택한 뉴스 리드문과 커뮤니티 본문 일부가 요약·해석을 위해 Anthropic API로 전달될 수 있습니다. 뉴스 요약은 기본 꺼짐, 커뮤니티 요약은 기본 켜짐입니다. 각 설정은 [설정 안내](configuration.md#위치와-섹션)를 참고하세요.

명시적 과제 명령은 LLM 없이 처리합니다. 캘린더 URL·토큰·과제 캐시·보유종목을 저장하는 위치와 실패 후 재시도 방식은 [운영 안내](operations.md)에 정리했습니다.

과거 Discord 메시지를 다시 읽을 때 상대적 마감일은 메시지 작성일(KST)을 기준으로 해석합니다. 실행일이 바뀌어도 과거 메시지의 “내일”이 매일 뒤로 밀리지 않습니다.
